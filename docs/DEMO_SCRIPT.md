# 5～8 分钟课堂演示

## 开始前

运行 `run.bat`。右侧默认只有一个中文面板，不用打开任何高级设置。

## 1. 一键开始（约 1 分钟）

点击「开始演示」。程序自动准备设备、启动输送机，再让采煤机开始割煤。
说明：这是 C++17 / OpenGL 3.3 教学仿真，准备过程仍遵守先开输送机、再允许割煤的联锁。

## 2. 看三种主要设备（约 2 分钟）

1. 点击「看采煤机」，镜头会跟随机器移动。观察滚筒旋转、喷水、煤块下落和换向。
2. 点击「看液压支架」，观察采煤机通过后支架依次降架、移架、升架。
3. 点击「看运煤」，观察交错链环与刮板把煤送往机头。
4. 点击「暂停演示」看细节，再点「继续演示」。两者是同一个按钮；也可以按空格。
5. 点击「全景俯视」展示整体布局。点击「看采煤机」返回跟随视角。

需要数据时再展开「设备详情」，选择设备查看速度、负载、温度或压力。

## 3. 展示图形学效果（约 1 分钟，可选）

打开「高级设置」的「画面」页，切换工作灯阴影、煤尘与喷雾、雾气、接触阴影。
「调试」页保留线框、坐标轴和包围盒。展示完折叠高级设置。

## 4. 演示故障与急停（约 2 分钟，可选）

1. 在「高级设置 → 故障演示」点击「模拟输送机堵塞」，观察采煤机停止。
2. 主按钮变为「排除故障并重新演示」，点击后会清除故障，按正常准备流程重新启动。
3. 点击「模拟紧急停止」，观察全部运动停止、主按钮禁用。
4. 急停后必须先点击主面板出现的「解除急停」，再点击「开始演示」。简化界面不会绕过锁定。
5. 开发用原始日志在「高级设置 → 日志」，普通观看无需打开。

## 收尾

「重新开始」让设备回到起点再演示。`F12` 保存截图，`Tab` 隐藏面板，`Esc` 退出。

如果自己移动后迷路，直接点击「看采煤机」即可；无需记住相机按键。

当前仍为程序化教学模型：未实现煤壁体积切削、真实矿压和工业 CAD 精度。
